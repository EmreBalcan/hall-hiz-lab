Analog sensör “var / yok” demez; alanla orantılı bir gerilim verir. Alan yokken OUT ≈ 2,5 V; S kutbu gerilimi yükseltir, N kutbu düşürür. Eşik kararını Arduino yazılımda verir: A1 ≥ 612 olunca yeni tur, A1 ≤ 583 olunca mıknatıs uzaklaştı (histerezis).

Model bağımlıdır: Duyarlılık (≈ 14 mV/mT) ve çıkış aralığı (≈ 0,9–4,2 V) SS49E için tipik değerlerdir; başka sensörde eşikler veri sayfasına göre yeniden hesaplanır.

Arduino kodu (hız ölçümü + PI hız kontrolü) 
// Analog Hall sensörü (SS49E) ile DC motor hız ölçümü ve PI kontrolü
// Kart: Arduino Uno R3 (ATmega328P, 16 MHz)
const byte HALL_PIN = A1;   // SS49E OUT → R1 (1 kΩ) → A1, C3 (100 nF) süzgeç
const byte PWM_PIN  = 9;    // MOSFET kapısı (R2 = 220 Ω), Timer1 ≈ 490 Hz
const byte POT_PIN  = A0;   // hedef hız potansiyometresi (RV1)

const int ESIK_UST = 612;   // ≈ 2,99 V ≈ 35 mT: mıknatıs geldi (yeni tur)
const int ESIK_ALT = 583;   // ≈ 2,85 V ≈ 25 mT: mıknatıs gitti

const float KP = 0.077;                     // PWM / RPM
const float KI = 0.64;                      // PWM / (RPM·s)
const unsigned long ZAMAN_ASIMI = 500000UL; // µs: 0,5 s geçiş yoksa motor durmuş sayılır
const unsigned long MIN_PERIYOT = 20000UL;  // µs: daha kısa aralıklı geçiş = parazit
const float DT_MAX = 0.1;                   // s: integral adımı üst sınırı
const byte  KALKIS_ADIM = 25;               // zaman aşımında PWM artışı (rampa)

bool miknatisVar = false;      // S kutbu şu an sensörün önünde mi?
bool ilkGecis    = true;       // önceki geçişin zamanı bilinmiyor
unsigned long sonGecis   = 0;  // son geçerli eşik geçişinin zamanı (µs)
unsigned long sonKontrol = 0;  // son kontrol adımının zamanı (µs)
int   tepe  = 0;               // son geçişteki en yüksek A1 değeri
float integ = 0;               // PI integral terimi (PWM birimi)
int   pwm   = 0;               // D9'a yazılan değer (0–255)

void setup() {
  pinMode(PWM_PIN, OUTPUT);
  analogWrite(PWM_PIN, 0);              // motor kapalı başlar
  Serial.begin(115200);
  sonKontrol = micros();
}

void loop() {
  int v = analogRead(HALL_PIN);         // 0–1023, bir okuma ≈ 112 µs
  unsigned long simdi = micros();

  if (miknatisVar && v > tepe) tepe = v;

  if (!miknatisVar && v >= ESIK_UST) {         // eşik yukarı geçildi: yeni tur
    miknatisVar = true;
    unsigned long T = simdi - sonGecis;
    if (ilkGecis) {                            // önceki geçiş yok: yalnızca kaydet
      ilkGecis = false;
      sonGecis = simdi;
    } else if (T >= MIN_PERIYOT) {             // geçerli tur
      sonGecis = simdi;
      kontrol(T, simdi);
    }
    tepe = v;
  }
  else if (miknatisVar && v <= ESIK_ALT) {     // mıknatıs uzaklaştı (sayılmaz)
    miknatisVar = false;
  }

  if (simdi - sonGecis > ZAMAN_ASIMI && simdi - sonKontrol > ZAMAN_ASIMI) {
    // motor duruyor ya da 120 RPM'den yavaş: kalkış rampası
    pwm = min(pwm + KALKIS_ADIM, 255);
    integ = pwm;
    analogWrite(PWM_PIN, pwm);
    ilkGecis = true;
    sonKontrol = simdi;
    Serial.print("Gecis yok  A1="); Serial.print(v);
    Serial.print("  PWM=");         Serial.println(pwm);
  }
}

void kontrol(unsigned long T, unsigned long simdi) {
  int   hedef = min(200 + 2 * analogRead(POT_PIN), 2000);  // 200–2000 RPM
  float rpm   = 60000000.0 / T;               // tur başına 1 geçiş
  float dt    = min(T / 1e6, DT_MAX);
  float hata  = hedef - rpm;
  integ = constrain(integ + KI * hata * dt, 0, 255);   // anti-windup
  pwm   = constrain(KP * hata + integ, 0, 255);
  analogWrite(PWM_PIN, pwm);
  sonKontrol = simdi;

  Serial.print("T=");        Serial.print(T / 1000.0, 1);
  Serial.print(" ms  RPM="); Serial.print(rpm, 0);
  Serial.print("  Hedef=");  Serial.print(hedef);
  Serial.print("  PWM=");    Serial.print(pwm);
  Serial.print("  Tepe=");   Serial.println(tepe);   // önceki geçişin tepe A1 değeri
}
Bölüm 3 · Çalışan devre

Devre simülasyonu: bir turda neler oluyor?

Gerçekte 600 RPM'de bir tur 100 ms sürer. Burada yavaş çekimde akımın yolu, sensör sinyali, RPM hesabı ve PWM ayarı adım adım gösterilir.

Kontrol Tur 0

1 tur ≈ 48 s · adım 6 s

Potansiyometre (hedef hız) A0 = 200 → 600 RPM

Bir turda olanlar

  1. 1
    PWM açık: D9 HIGH, motora gerilim verilirD9 = 5 V → MOSFET iletimde → motor akımı

    Arduino motoru doğrudan çalıştıramaz: bir pin en fazla yaklaşık 20 mA verebilir, motor ise yüzlerce mA çeker. Bu yüzden D9 pini yalnızca MOSFET'in (Q1) kapısını (gate) kontrol eder. MOSFET de 12 V'luk motor akımını açıp kapatan elektronik bir anahtar gibi çalışır.

    D9 HIGH (5 V) olduğunda akım R2 (220 Ω) üzerinden MOSFET'in kapısına gider ve kapıyı mikrosaniyeler içinde doldurur (beyaz noktalar). Kapı gerilimi eşiği (yaklaşık 1–2 V) geçince MOSFET'in drain–source yolu iletime geçer ve direnci yalnızca yaklaşık 0.025 Ω olur.

    Böylece akım 12 V kaynağın + ucundan motora, motordan MOSFET'in drain ucuna, oradan source üzerinden GND'ye ve kaynağın − ucuna geri döner (mavi noktalar). Motor bu sürede tam 12 V görür, akımı artar ve hızlanmaya çalışır.

  2. 2
    PWM kapalı: D9 LOW, akım diyottan dönerD9 = 0 V → MOSFET kesimde · görev oranı

    D9 LOW (0 V) olunca kapıdaki yük boşalır; R3 (10 kΩ) kapıyı GND seviyesinde tutar. MOSFET kesime geçer ve 12 V kaynaktan motora akım gitmez.

    Ancak motorun içi bir bobindir ve bobindeki akım bir anda sıfırlanamaz. Akım D1 diyotu üzerinden motorun + ucuna geri dönerek küçük bir döngü oluşturur ve yavaşça azalır (mor noktalar). D1 olmasaydı bu akım MOSFET üzerinde yüzlerce voltluk bir gerilim sıçraması yaratır ve onu bozabilirdi.

    D9 saniyede 490 kez HIGH ve LOW olur; bir periyot 1 / 490 = 2.04 ms'dir. Bu periyot hiç değişmez. Değişen, HIGH süresinin periyoda oranıdır: buna görev oranı denir. analogWrite(9, 89) yazıldığında HIGH süresi 89 / 255 = %35 olur.

    Motor bu hızlı açılıp kapanmayı tek tek hissetmez, ortalamasını hisseder: ortalama gerilim ≈ görev oranı × 12 V. Görev oranı arttıkça HIGH süresi uzar, motor daha uzun süre 12 V görür ve hızlanır; azaldıkça yavaşlar. Simülasyonda PWM izlenebilsin diye çok yavaşlatıldı.

  3. 3
    Mıknatıs sensöre yaklaşıyorOUT 2,5 V’tan yükseliyor · A1 < 612

    Motor milindeki diskte bir N (kırmızı) ve bir S (mavi) kutbu vardır. Disk milde döner; SS49E sensörü ise sabit bir braket üzerindedir ve dönmez.

    SS49E analog bir sensördür: çıkış gerilimi alanla orantılıdır. Alan yokken OUT ≈ 2,5 V'tur; S kutbu yaklaştıkça her 1 mT için yaklaşık 14 mV yükselir (N kutbu ise düşürür). Bu gerilim R1 (1 kΩ) üzerinden Arduino'nun A1 girişine gider; C3 (100 nF) ile birlikte hızlı gürültüyü süzer (sarı noktalar).

    Arduino loop() içinde A1'i sürekli okur (analogRead, ≈ 0,12 ms). Alan henüz 35 mT'nin altındayken okunan değer 612'den küçüktür, yazılım beklemeye devam eder. Sensör 5 V hattından birkaç mA çekerek çalışır (yeşil noktalar).

  4. 4
    Gerilim eşiği geçti: yeni turA1 ≥ 612 (≈ 2,99 V ≈ 35 mT)

    S kutbu sensörün önüne gelince alan 35 mT'yi geçer: OUT = 2,5 + 0,014 × 35 ≈ 2,99 V olur. Arduino'nun ADC'si bunu 2,99 / 5 × 1024 ≈ 612 olarak okur.

    Kodda if (!miknatisVar && v >= ESIK_UST) koşulu sağlanır: miknatisVar = true yapılır ve bu an “yeni tur” kabul edilir. Diskte tek S kutbu olduğu için bu geçiş her turda bir kez olur.

    Dijital sensörden farkı: eşik kararını sensör değil yazılım verir. Analog pin kesme üretmediği için Arduino geçişi kesmeyle değil, A1'i sürekli okuyarak yakalar.

  5. 5
    Tur süresi T ölçülürT = şimdiki geçiş − önceki geçiş

    Eşik geçildiği anda micros() okunur. Bir önceki geçişin zamanı sonGecis değişkeninde saklıdır.

    İkisinin farkı T, mıknatısın tam bir tur atması için geçen süredir. Ardından şimdiki zaman yeni sonGecis olur ve kontrol(T) çağrılır.

    Zaman, A1 okumaları arasında (≈ 0,12 ms) yakalanır; 600 RPM'de bir tur 100 ms olduğundan hata en fazla ≈ %0,12'dir. Bu adımda kablolarda yeni bir akım yoktur; her şey Arduino'nun içinde olur.

  6. 6
    Hız hesabı: RPM = 60 / Tkodda: 60 000 000 / T(µs)

    kontrol(T) fonksiyonu T'yi hıza çevirir. Kesme kullanılmadığı için değişkenleri korumaya (noInterrupts) gerek yoktur; her şey loop() içinde sırayla olur.

    Bir tur T saniye sürüyorsa motor saniyede 1/T tur, dakikada 60/T tur atar. T mikrosaniye cinsinden tutulduğu için kodda formül 60000000.0 / T olarak yazılır. Devir başına bir darbe olduğu için ayrıca bölmeye gerek yoktur; diskte 2 S kutbu olsaydı sonuç 2'ye bölünürdü.

    Bu periyot yöntemi her turda yeni bir hız değeri verir. 1 saniye boyunca darbe saymaktan çok daha hızlı tepki verdiği için hız kontrolüne uygundur.

  7. 7
    Hedefle karşılaştır, yeni PWM'i hesaplaA0 okunur → PI kontrol → analogWrite(9, pwm)

    Arduino potansiyometreyi analogRead(A0) ile okur. Potansiyometrenin orta ucu 0–5 V arasında bir gerilim verir (yeşil noktalar); Arduino'nun ADC'si bunu 0–1023 arası bir sayıya çevirir. Kodda hedef = 200 + 2 × A0 RPM alınır ve en fazla 2000 RPM ile sınırlanır. 2000 RPM, motorun tam 12 V (PWM 255) ile ulaştığı hızdır; potansiyometre sona yaklaştıkça PWM 255’e çıkar.

    Hata = hedef − ölçülen. Hata pozitifse motor hedeften yavaştır, negatifse hızlıdır. PI kontrolcü iki parçadan oluşur: P (orantısal) kısmı hatanın o anki büyüklüğüne göre hemen tepki verir; I (integral) kısmı hata sürdükçe her turda birikir ve motoru sonunda tam hedefe oturtur.

    Toplam 0–255 aralığına sınırlanır ve analogWrite(9, pwm) ile D9'a yazılır. Yeni değer bir sonraki PWM periyodundan itibaren geçerlidir. Etkisini bir sonraki turun 1. ve 2. adımında görürsünüz: HIGH süresi uzar ya da kısalır.

  8. 8
    Mıknatıs uzaklaşıyor, A1 alt eşiğin altına iniyorA1 ≤ 583 · bu geçiş sayılmaz

    S kutbu sensörün önünden geçerken alan 35 mT'nin üstünde kalır; A1 de 612'nin üstündedir ve miknatisVar true kalır.

    Disk döndükçe S kutbu uzaklaşır, alan ve OUT gerilimi azalır. Alan 25 mT'nin altına inince OUT ≈ 2,85 V, A1 ≈ 583 olur ve kod miknatisVar = false yapar. Bu geçiş tur olarak sayılmaz.

    İki eşik arasındaki fark (612 ile 583, yani histerezis), gerilim eşik sınırında gürültüyle titrerken tek tur yerine birden fazla tur sayılmasını önler. Disk dönmeye devam eder ve bir sonraki turda döngü 1. adımdan (PWM) yeniden başlar.
